# Л1 
Разработать калькулятор. В качестве операндов использовать два числа, каждое из которых от 0 до 9. Поддерживаемые операции: +, -, *,/. Выбор операции осуществляется посредством клавиши *. Результат вычисления появляется на семисегментном индикаторе после нажатия на #.
